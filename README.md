# Tradata A250 Booth Game

Small Python game used at the Tradata A250 booth.

## Live App

This repository is ready to deploy as a live Streamlit app. Once deployed, the app can be opened directly from any device with this link:

https://share.streamlit.io/Dannywinson1/tradataa250boothgame/main/app.py

## How to deploy

1. Go to https://share.streamlit.io
2. Sign in with GitHub
3. Create a new app
4. Select repository: `Dannywinson1/tradataa250boothgame`
5. Branch: `main`
6. File path: `app.py`

## Run locally

```bash
git clone https://github.com/Dannywinson1/tradataa250boothgame.git
cd tradataa250boothgame
python -m pip install -r requirements.txt
streamlit run app.py
```
